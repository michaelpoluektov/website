# Personal website project guidance

1. Avoid heavy libraries and unnecessary JavaScript. Website should run with JavaScript disabled
2. Prefer an engineering tone in the language used, do not generate actual content: generate placeholders to be filled in
3. When writing code make sure it's type safe and linted and whatnot

# Communication guidance

1. Treat the user as an engineer: review important decisions with them, do not implement hacks or workarounds without explicit approval
2. Do not make code changes unless the user explicitly requests code changes
3. Avoid calling `git add` or `git commit` yourself
4. Avoid editing `README.md`, keep agent docs in `agent-docs/`
